Accessibility

Accessibility statement

We want this website to work for as many people as reasonably possible, including people with disabilities.

We're working toward recognized accessibility practices, including:

  • Semantic headings and landmarks
  • Keyboard-accessible navigation and forms
  • Visible focus indicators
  • Sufficient color contrast
  • Text alternatives for meaningful images
  • Form labels and understandable error messages
  • Reduced-motion preferences
  • Responsive layouts and browser zoom

Accessibility is ongoing work. If you have trouble using the site or getting information, email hello@primeaiconsultants.com and tell us the page, the feature, and what you need. We'll make reasonable efforts to provide an accessible alternative and to improve the experience.

This statement does not claim conformance that has not been tested. After formal testing, we may state a specific target such as WCAG 2.2 Level AA only if the implementation and test record support that statement.
