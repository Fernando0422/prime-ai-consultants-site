# Prime AI Consultants: Website Repo

This repo holds the public website for Prime AI Consultants, a consultancy based in Santa Clarita, CA. The site is plain static HTML pages with no build step, deployed via Vercel from the main branch.

## Standing rules for anyone editing this site

- Never publish prices anywhere in copy. Pricing is set after the first conversation and given as a written estimate.
- Never use the word "practice" in client-facing copy. Use "Services for Manufacturers", "Services for Legal Professionals", and "Services for Local Businesses".
- The first conversation is free on every path.
- Terminology: "audit" for local businesses, "diagnostic" for law and manufacturing.
- The local audit and the law diagnostic are free. The manufacturing diagnostic is scoped and priced on the first call.
- Fernando Rojas runs the first conversation on every engagement. Antonio Rojas leads manufacturing diagnostics.
- Clients own everything Prime builds for them. Teaching the owner to run it is part of the work.
